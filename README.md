# Лабораторные работы по веб-программированию

Выполнила: Умралиева Надежда Рафаэльевна  
Группа: K3323

## Состав репозитория

- `lab1` — задания 1, 2 и 3: HTTP-заголовки, функция с `this`, Promise и Fetch;
- `lab2` — задания 4 и 5: обработка HTTP-запросов, дата и переворот строки;
- `lab3` — приложение Express: маршрутизация, SHA-1 и серверный HTTP-запрос.

В каждой папке находятся исходный код лабораторной работы и соответствующий PDF-отчёт.

## Запуск

Для запуска требуется Node.js 22 или новее.

```bash
cd lab1
npm ci
npm start
```

Для второй и третьей лабораторных используется тот же порядок запуска из соответствующей папки.
